# Enterprise Data Platform Lab (EDPL)

> **A production-inspired, open-source learning platform for mastering modern Data Engineering through hands-on labs, architecture, and real-world projects.**

---

## 📖 Overview

Enterprise Data Platform Lab (EDPL) is an open-source educational project designed to teach **modern Data Engineering** from fundamentals to production-ready architectures.

Unlike traditional courses that focus on individual technologies, EDPL emphasizes **system design**, **architecture**, **engineering principles**, and **real-world implementation**.

The goal is not only to learn how to use tools, but also to understand **why** they exist, **when** they should be used, and **how** they fit together in an enterprise-scale data platform.

---

## 🎯 Vision

Build the most comprehensive open-source Data Engineering Lab for learning modern Enterprise Data Platforms using open-source technologies.

The project focuses on:

- Architecture before implementation
- Engineering principles instead of tool memorization
- Production-inspired environments
- Hands-on learning
- Best practices used in modern data teams

# Why EDPL?

Most tutorials teach technologies separately.

For example:

- Spark Tutorial
- Kafka Tutorial
- Flink Tutorial

Real-world systems are different.

Enterprise Data Platforms combine multiple technologies into a single architecture.

EDPL teaches how these technologies work together.

---

Every module follows the same structure.

